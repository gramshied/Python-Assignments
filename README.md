# Basic Python Programs

This repository contains two simple Python programs designed for beginners to understand basic input/output operations, arithmetic calculations, and string formatting in Python.

## Program 1: Basic Arithmetic Calculator

This program prompts the user to enter two numbers and performs the following operations:
- **Addition**
- **Subtraction**
- **Multiplication**
- **Division**

## Program 2: Welcome Message Generator

This program collects the user's first and last name and prints a personalised welcome message.

## Purpose

These programs are intended for educational purposes and demonstrate:
- Taking user input using `input()`
- Performing arithmetic operations
- Formatting and displaying output using `print()`
